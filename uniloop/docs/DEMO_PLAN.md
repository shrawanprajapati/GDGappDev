# UniLoop Demo Plan

1. Log in as Industry and post a project.
2. Log in as Student, open Find Project, and submit an application.
3. Return to Industry, review applicants, shortlist one, and move it in Hiring Pipeline.
4. Open Student Workspace, add a task, view Kanban, submit a milestone, and report an issue.
5. Open milestone feedback and Project History.

Target duration: 3–5 minutes. All data is local and deterministic.
